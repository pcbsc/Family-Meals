# Family Menu 🍚

Our family's own digital menu: every dish we love, with recipes, photos and ratings,
plus a weekly meal plan and a shopping list that makes itself. Simple enough for a
7-year-old: big pictures, big buttons, very little reading.

- **Today**: what's for breakfast, lunch, dinner and snack. When a grown-up sets out
  2–3 choices, the kids pick tonight's dinner. Every planned meal has a **🔄 Change** button
  (with a grown-up PIN, kids get **🙋 Ask for something else** instead, so a dinner that's
  already shopped for doesn't change). After dinner, **🍽️ We ate it!** opens one sheet:
  faces 😍 😋 😐 😖 for everyone, Brave Bites stickers, what got used up, leftovers for
  tomorrow's lunch or the freezer, and a note for next time ("less sugar"), which shows on
  the recipe the next time you make it.
- **Changing your mind is one tap**: tap a meal spot (or 🔄 Change) and pick one of four
  **🔄 Try something else** ideas (🎲 for more), **📆 Move it to another day** (it swaps with
  what's there), **🍱 Make extra for lunch tomorrow**, or use a **🧊 freezer meal**. Every
  change shows an **Undo** button, including filling, copying, Claude's plan and clearing
  the week. A dinner cooked double takes its leftover lunch along when it moves, and takes it
  off when it's removed. An empty week offers **📋 Same as last week**. **📅 Plan it** on a
  recipe asks whether to have it instead of what's planned, or add it as a side.
- **Week**: plan seven days. Tap a spot to pick a dish, add sides, or let the kids choose.
  **✨ Fill our week** offers two choices: **Use our favorites** fills the empty spots from
  the dishes the family rates highest, and keeps the week balanced: one noodle and one fried
  dinner at most, a different protein each night, fish when there's a fish dish, 40 minutes or
  less on school nights, and a banchan with each Korean dinner. **Ask Claude** builds a
  balanced, healthy week (using what's in the fridge and freezer, and everyone's allergies and
  dislikes) and finds new recipes from Seonkyoung Longest and other well-known cooks.
- **Menu**: all our dishes as picture tiles. Swipe the flag buttons to see one kind of food
  (🇰🇷 Korean, 🇺🇸 American, 🇮🇹 Italian, 🇲🇽 Mexican, 🇨🇳 Chinese, 🇯🇵 Japanese, 🇮🇳 Indian,
  🇹🇭 Thai, 🫒 Mediterranean). Each dish has servings you can change (the ingredients
  rescale), steps, tips, food photos, hearts and everyone's faces.
  **👩‍🍳 Cook together** shows one big step at a time with the amounts that step uses, a
  **🧒 Your job** for the kids (rinse, crack eggs, snip green onions, roll kimbap, fill mandu,
  sprinkle, be the timer captain…), a grown-up badge only for knives, the stove and the oven,
  read-aloud, and several timers at once (the rice keeps going while the next step's timer
  runs). 🔊 next to a Korean name says it in Korean.
- **🥗 Healthy · 🌶️ how spicy · ⚖️ cups or grams**: switches that change the ingredients,
  steps and shopping list. Settings sets the family's way; on a recipe, Healthy and spice are
  just for that recipe (so a kid trying 🔥 Spicy on one dish doesn't change them all). Healthy
  swaps in brown rice (not for kimbap, which needs sticky rice), low-sodium soy sauce,
  whole-wheat pasta and bread, lean meat and less sugar (a quarter less in baking, none taken
  from a glaze), and air-frying instead of deep-frying, with the frying steps rewritten.
  **Mild** leaves out gochugaru and fresh chilies, halves the gochujang, rinses the kimchi and
  uses half the spicy ramen packet; the spiciest dishes (tteokbokki, jeyuk, dakdoritang…) say
  how to make the kids' soy-sauce version. **Spicy** adds more, for kids who love it hot. If
  one person likes it mild, the steps say when to scoop out their share.
  Grams turns cups, pounds, ounces, °F and inches into grams, ml, °C and cm.
  **🖨️ Print recipe card** prints just the recipe.
- **🧊 What can we make?** (top of the Menu): tap or type what's in the fridge. It shows the
  dishes that are ready to cook, and the ones that need just a thing or two, with a button to
  put those things on the shopping list. Salt, oil, sauces and spices count as already there.
- **Shop**: one combined list of everything the week's meals need, plus any recipe you add
  with **🛒 Add to shopping list** on its page. The same ingredient from different dishes is
  one line, with the total amount and which dishes it's for, sorted by aisle (including an Asian-market
  aisle), with the cupboard basics folded away. Tick things off, or send the list to a phone.
  Things we already have are set aside under **✅ We have these** (with the day we got them);
  **🏠 Done shopping** puts everything ticked into "what we have", and after cooking you tap
  what got used up. Fresh food (veggies, meat, eggs, milk) goes back on the list after a week
  unless you say it's still there; onions don't count as green onions, nor chicken as chicken
  broth. Things you type in are sorted into their aisle. Leftover lunches and freezer meals
  aren't shopped for twice.
- **📱 Shared shopping list** (optional): both grown-ups' phones tick the same list, live.
  See [Shared shopping list](#shared-shopping-list) below.
- **🏅 Brave Bites**: a sticker chart for trying foods. Kids learn to like a food by tasting it
  again and again (in studies, about a dozen tiny tastes, each with a sticker). So a grown-up
  picks one or two **Brave Foods** per kid, and every try earns an animal sticker, up to 12 per
  food. A dish tried for the very first time earns one too. Ten stickers and **🏆 they pick a
  dinner**.
- **🍽️ Food for each person** (Settings → 🍽️ next to a name): allergies, dislikes, how spicy,
  and foods they always eat. A dish with an allergy gets a red warning (sauces count: soy
  sauce and gochujang have wheat and soy), and the fill buttons, ideas, the kids' wish screen
  and Claude never pick it. A dislike says to serve it on the side.
- **📆 Calendar**: Week → ⋯ → **Put our dinners on the calendar** makes a calendar file that
  Google Calendar, Apple Calendar or Outlook can add.
- **Add a dish**: paste a link (recipe sites, Instagram, TikTok, YouTube), snap a photo
  of a cookbook page or a screenshot, paste a caption, or write our own.
- **📺 Videos**: a dish can have a YouTube, TikTok or Instagram video. It plays right on the
  dish page, and in **Cook together** the 📺 button keeps it above the steps while you cook.
- **🙋 I want to eat…**: kids make wishes from a dozen big pictures (or say it with 🎤 where
  the browser can listen), and the grown-ups see them when planning.

It starts with 152 family recipes, 148 of them with a cooking video. Most are Korean and
Korean-American: 66 Korean dishes (bulgogi, japchae, tteokbokki, rosé tteokbokki, dakgangjeong,
budae jjigae, jjimdak, mandu, gyeran jjim, kimbap…), 10 Korean fusion favorites (bulgogi tacos,
kimchi quesadillas, kimchi mac & cheese, bulgogi cheesesteaks, gochujang wings, gochujang
salmon…), and 25 spicy dishes for kids who like the heat. There are also
American family dinners (turkey chili, mac & cheese, fish sticks, banana oat muffins…),
Italian (lasagna, meatballs, minestrone, pesto pasta), Mexican (enchiladas, burrito bowls,
tortilla soup, guacamole), Chinese (egg fried rice, beef & broccoli, potstickers, tomato &
egg), Japanese (katsu, oyakodon, curry rice, miso soup), Indian (mild butter chicken, dal,
chana masala), Thai (pad thai, satay, yellow curry) and Mediterranean (souvlaki, falafel,
shakshuka), plus 7 dishes that went viral on TikTok and Instagram that home cooks tested and
liked. If you already use the app, new recipes and videos appear on their own the next time
it opens (dishes you deleted stay deleted, and a video you took off stays off).

## 1. Put it online (once, about 2 minutes)

The app is a website that installs on the tablet like a real app. GitHub hosts it for free,
but only for **public** repositories (private ones need a paid plan).

1. On GitHub, open this repository → **Settings**. At the bottom of the **General** page,
   under **Danger Zone**, choose **Change visibility → Make public**.
2. Still in **Settings**, open **Pages** (left side).
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to **main** and the folder to **/ (root)**, then **Save**.
5. Wait a minute or two. The address appears at the top of that page:
   **https://pcbsc.github.io/Family-Meals/**

Only the app's code is public. Your recipes, photos, ratings and Claude key stay on
your own device and are never uploaded to GitHub.

## 2. Install it on the Android tablet or phone

1. Open **https://pcbsc.github.io/Family-Meals/** in **Chrome**.
2. Tap the **⋮** menu → **Install app** (on some phones it's **Add to Home screen**).
   The app may also offer an **Install** button on its Today screen.
3. Open **Family Menu** from the home screen and follow the welcome steps: family
   names and faces, then the starter dishes.

### Or: the real Android app

There is also a proper Android app (an APK) that you install like any other app. It works
the same as the website, plus: it opens straight from the app drawer, appears in the Share
menu for links, posts and screenshots, reads recipes aloud with Android's own voice, keeps
the screen on while cooking, and saves backups and calendar files through Android's share
sheet (pick **Drive**, **Gmail** or **Files**).

1. On the phone or tablet, open
   **https://github.com/pcbsc/Family-Meals/releases/download/app-latest/family-menu.apk**
   in Chrome and download it.
2. Tap the downloaded file. Android asks to allow installs from Chrome the first time:
   tap **Settings → Allow from this source**, go back, then **Install**.
3. If **Play Protect** warns that it doesn't recognize the app, tap **More details →
   Install anyway**. It warns because the app isn't from the Play Store.

To update, download and install the same link again. Your recipes stay. Every change pushed
to this repository builds a new version (see the **Actions** tab).

**Moving from the website to the app:** the app keeps its own copy of everything, separate
from the website. In the website version, tap **⚙️ → 💾 Save backup file**. Then in the
app, tap **⚙️ → 📂 Restore from file** and paste your Claude key again (keys aren't in
backups).

**About the signing key:** Android only installs an update if it's signed with the same key
as the first install, so the key is kept in this repository
(`android/app/family-menu.keystore`). Because the repository is public, anyone could sign an
app with it. Only install Family Menu from the link above.

## 3. Turn on Claude (recommended)

Claude is the AI helper that turns links, Instagram/TikTok posts and photos into recipe
cards, and plans the week. It needs a key from an Anthropic account:

1. Go to **https://console.anthropic.com** and sign in (or sign up).
2. Under **Billing**, add a little credit. $5 lasts a long time.
3. Under **API keys**, create a key and copy it.
4. In Family Menu tap **⚙️** (top right of Today) → paste the key under
   **✨ Claude** → **Save & test**.

**Cost:** about 10–15¢ to import a recipe, a few cents to find a video, and 25–40¢ to plan
a week that includes new dishes from the web. "Use our favorites" and everything else are
free and work offline (videos need the internet).

The key is saved only on this device. It isn't put in backup files, and it's only ever
sent to Claude.

**What Claude sees:** the link, caption or photo you import. When finding a video: the
dish's name, description and ingredients. When planning a week: your
dish names and ratings, the food notes in Settings, and the family's first names (so the
plan can say who asked for what). Nothing else leaves the device.

## Sharing recipes from Instagram or TikTok

After the app is installed (step 2), Android lists it in the **Share** menu:

1. In Instagram or TikTok, open the post and tap **Share** (the paper airplane or arrow).
2. Choose **Family Menu**. If you don't see it, tap **More** or **Other apps**.
3. Claude reads the post, finds the creator's written recipe if there is one, and
   opens the recipe form so you can check it, add a photo and tap **Save**.

If the recipe only exists in the video, Claude rebuilds it from the caption and says
it had to guess, so check the amounts. If a post is private, copy its caption or take a
screenshot and share or paste that instead. Screenshots can be shared straight to
Family Menu too.

## Videos

- **Starter recipes** come with a video: the creator's own TikTok for the trending dishes, and
  a YouTube video from a well-known cook (Maangchi, Natasha's Kitchen, Made With Lau, Just One
  Cookbook, Rick Bayless, Hot Thai Kitchen…) for the rest.
- **Recipes from a video** (a TikTok, Instagram reel or YouTube link) keep that video
  automatically. Recipes from a website keep the creator's video when the page has one, and
  if there's no Instagram or TikTok video, Claude looks for a YouTube one.
- **Any other dish:** open it and tap **📺 Add a video** (at the bottom). Then either
  **✨ Find one for me** (Claude searches YouTube, TikTok and Instagram and picks a good one
  from a well-known cook), or **🔎 Look on YouTube**, tap **Share → Copy link** on the video
  you like, come back and paste it. You can also paste a link into **Video link** in Edit.
- **While cooking:** in **Cook together**, tap **📺** at the top. The video stays above the
  steps while you swipe through them; tap 📺 again to hide it.
- To change or remove a video, tap **Change** next to it.

Only a YouTube preview picture loads before you tap ▶ (TikTok and Instagram show a plain
▶ until then), and videos need the internet. A
short TikTok share link (vm.tiktok.com/…) opens in TikTok instead of playing in the app.
For a starter recipe, the video is the creator's version, so their amounts may differ a little.

## Shared shopping list

Both phones can tick the same shopping list, a few seconds apart. Because the app has no
server of its own, the list lives in your own free Firebase project (Google's free "Spark"
plan is plenty). Set it up once, on a computer, in about 10 minutes:

1. Go to [console.firebase.google.com](https://console.firebase.google.com), sign in with a
   Google account and **Create a project** (any name, like "our-family-menu"). Google Analytics
   isn't needed.
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable → Save.**
3. **Build → Firestore Database → Create database.** Pick a location near you and start in
   **production mode**.
4. In Firestore, open the **Rules** tab, replace everything with this and **Publish**:

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /families/{family} {
         allow get, create, update: if request.auth != null && family.size() >= 24;
       }
     }
   }
   ```

5. **Project settings** (⚙️ next to Project Overview) → **General** → **Your apps** → the
   **</>** (Web) button. Give it a nickname and **Register app**. Copy the `apiKey` and the
   `projectId` it shows.
6. On the planning phone: **⚙️ Settings → 📱 Shared shopping list**, paste both and tap
   **Start sharing**. Then **📤 Send the join link** to the other phone and open it there.

The planning phone keeps the list up to date from the week's plan; the other phone sees the
same list, ticks things off and adds extras. **🏠 Done shopping** on either phone puts what was
bought into the planning phone's "what we have". The Firebase key is meant to be public (it
only identifies the project); what keeps the list private is the long, random family code in
the join link, so only send it to family. Only the shopping list is shared: recipes, photos and
the plan stay on each device. **Stop sharing** in Settings turns it off.

## Grown-up PIN

In **⚙️ Settings → 🔒 Grown-up PIN**, set a 4-digit PIN. Then Settings, editing,
deleting and clearing the week ask for it. If you forget it, tap **Forgot the PIN?** on the
PIN screen and answer the sum it shows; that removes the PIN. Kids can still look at everything, cook along,
rate, wish, add photos and pick dinner.

## Backups (important)

Because everything lives on the device, save a backup now and then:
**⚙️ Settings → 💾 Save backup file**. It saves one file (with all recipes and photos)
to Downloads. Keep a copy in Google Drive or email it to yourself. To move to a new
tablet, install the app there and use **📂 Restore from file**. The app reminds you
monthly.

## For developers

A static web app with no build step. Open `index.html` through any web server.

| Path | What it is |
|---|---|
| `index.html`, `styles.css` | Page shell and all styles |
| `js/app.js` | Starts the app and routes `#/screens` |
| `js/views/*.js` | One file per screen (`fridge.js` is "What can we make?" and the freezer, `stickers.js` is Brave Bites) |
| `js/store.js` | In-memory data plus saving to IndexedDB |
| `js/components.js`, `js/ui.js` | Shared pieces: tiles, sheets, PIN pad, photos |
| `js/recipe.js` | Ingredient parsing, servings scaling, shopping list, timers, what-can-we-make matching, healthy swaps, spice levels, metric |
| `js/planner.js` | Dates, the no-AI "Use our favorites", "Try something else" ideas, the calendar file |
| `js/share.js` | The shared shopping list (Firebase Auth and Firestore over plain REST) |
| `js/ai.js` | Claude: recipe import, finding videos and week planning |
| `js/video.js` | Turns YouTube / TikTok / Instagram / Vimeo links into players |
| `js/seed.js`, `js/seed-fusion.js` | Starter recipes (in batches; batch 4 is Korean and Korean fusion) and the "Ideas from famous cooks" list |
| `sw.js`, `manifest.webmanifest` | Offline support and the Android share target |
| `img/canva/` | Pictures from our Canva design "Family Menu phone app screens": the tomato mascot, animal stickers, meal and button icons |
| `vendor/` | The official Anthropic SDK bundled as one module |
| `js/native.js` | In the Android app only: files, sharing, reading aloud and keep-awake through Capacitor plugins, and posts shared from other apps |
| `android/`, `capacitor.config.json` | The Android app ([Capacitor](https://capacitorjs.com)): `SharedTextPlugin.java` receives the Share menu |
| `.github/workflows/android.yml` | Builds and signs the APK on every push to `main` and publishes it as the `app-latest` release |

```sh
npm install        # dev tools only: esbuild, Playwright, the SDK source
npm test           # unit tests, including fuzz tests (3,000 random inputs each)
npm run fuzz       # the fuzz tests with 30,000 inputs each
npm run lint       # eslint (installed separately)
npm run e2e        # drives the app in Chromium with Claude's API mocked
npm run vendor     # rebuild vendor/anthropic-sdk.mjs and the font after an upgrade
npm run icons      # re-render icons/*.png from icons/icon.svg
npm run serve      # http://localhost:8080
npm run www        # copy the files in sw.js's APP_FILES into www/ for the app
npm run android:sync   # www/ plus `cap sync`; then `cd android && ./gradlew assembleRelease`
```

Claude calls go from the browser straight to the API with the family's key
(`dangerouslyAllowBrowser`), because there is no server. They use `claude-opus-5-5`
with the `web_fetch` / `web_search` server tools and a client tool that returns the
structured result. They also handle `pause_turn`, retry when the result is incomplete,
and opt into server-side fallbacks (`fallbacks: "default"`) in case a request is
declined. If you add a file the app needs offline, list it in `APP_FILES` in `sw.js`
and bump `VERSION`.

Video players can only come from the sites in `PLAYER_ORIGINS` (`js/video.js`), which must
match `frame-src` in the page's Content-Security-Policy (a unit test checks). Player links are
rebuilt from the parsed video id, never copied from what was pasted. Claude's "find a video"
answer is only accepted if that video was in its web-search results. To add starter recipes,
add them to a new batch in `js/seed.js` and raise `LATEST_STARTER_BATCH`; families who
use the starter menu get the new batch once.
